# Module 01: Introduction to AI & Python

## Overview
This repository contains my learning notes and Python practice programs for Module 01: Introduction to AI & Python.

**Duration:** Day 1 – Day 4  
**Level:** Beginner

## Learning Objectives
1. Understand the basics of Artificial Intelligence and Machine Learning.
2. Learn the differences between AI, ML, and Deep Learning.
3. Explore real-world applications of AI.
4. Practice Python variables, data types, loops, functions, and lists.
5. Develop beginner-friendly Python programs.

## How to Run

Install Python 3 and clone or download this repository.

Run a program from the repository root:

```bash
python python-programs/01_hello_world.py
```

Replace the filename to run another program.
