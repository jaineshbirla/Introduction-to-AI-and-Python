This repository documents my learning journey through Module 01: Introduction to AI & Python.

**Duration:** Day 1–Day 4  
**Level:** Beginner

- Learn the fundamentals of Artificial Intelligence and Machine Learning.
- Understand the differences between AI, ML, and Deep Learning.
- Explore real-world applications of AI.
- Learn Python variables, data types, loops, functions, and lists.

## Repository Structure
- `learning-notes/` — Notes covering AI fundamentals and Python concepts.
- `python-programs/` — Python programs created during practice.
- `requirements.txt` — Project dependencies.

## Technologies
- Python 3
- Git and GitHub

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the repository directory.
4. Run a program using:

   `python python-programs/01_hello_world.py`

Replace the filename to execute another program.
